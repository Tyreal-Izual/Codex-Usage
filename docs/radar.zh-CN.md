# Codex 降智雷达

[快速开始](../README.zh-CN.md) · [English](radar.md)

Radar 读取[官网首页](https://codexradar.com/#stationmaster-round)的降智雷达总分面板，
默认启用，可在设置中暂停。

## 数据与展示

- 适配四分项评测（秦始皇、庞贝、鹈鹕、糖果），共 46 个配置；直接读取已发布总分，不重算分项。
- 分数保留两位小数，进度条固定为**分数 ÷ 150**，在 50、100 处分隔；默认彩色顶边，悬停时整圈高亮。真实零分显示 `0.00`，未测显示 `—`；旧 IQ/RadarBench 缓存不能回退使用。
- 六列等宽：ultra → max → xhigh → high → medium → low。Luna 没有 ultra；不支持的档位留空。窄窗口所有模型行一起横向滚动，不显示费用、耗时或历史曲线。
- 本地同步时间与官网测试时段分别显示，测试时段转换为 Mac 时区；同步成功不代表产生了新一轮评测。

## 刷新与缓存

应用运行且来源启用时每四小时抓取一次；普通刷新仅读取快照。每次请求 socket 超时
20 秒、响应上限 4 MiB。超时、连接错误及 HTTP 502/503/504 最多额外重试两次，
间隔 1 秒、3 秒；证书或解析错误不立即重试。

整轮失败后保留最后有效快照，按 15、30、60、120、最多 240 分钟退避重试。
不完整、格式错误或更旧的面板不会覆盖缓存。暂停/退出可中断重试等待，休眠或离线会延迟工作。
官网 HTML 变化可能需要更新适配器。

缓存为[公共缓存目录](development.md#configuration)下的 `codex_radar_snapshot.json`。
源码环境手动更新前先完全退出 Usage，结束后再打开：

```sh
python3 codex_radar.py --force
# 可指定其他缓存文件：
python3 codex_radar.py --cache /tmp/radar.json --force
```

分数来自社区评测，不代表账户用量或官方模型评分。
